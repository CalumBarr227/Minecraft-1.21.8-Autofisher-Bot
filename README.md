# Minecraft-1.21.8-Autofisher-Bot

I wanted to auto fish in my Minecraft Hardcore world, so I decided to make a simple Python bot to do it for me.

The bot uses OpenCV image recognition to detect the fishing splash/text on the screen. When detected, it automatically right-clicks to reel in the fish and then right-clicks again to recast the rod.

## Technologies
* Python
* OpenCV
* PyAutoGUI
* NumPy

This was a small project made for fun and to experiment with screen recognition and automation.
